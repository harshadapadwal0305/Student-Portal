# 🎓 Student Portal – Student Management System

A web-based Student Management System developed using **Python FastAPI, HTML, CSS, and JavaScript**. This project provides an interactive dashboard to manage student records and monitor academic performance.

## 🚀 Features

- **Dashboard:** Displays total students, placed students, not placed students, average marks, highest marks, and placement percentage.
- **Student Records:** View all student details in an organized table.
- **Add Student:** Add new student records.
- **Edit Student:** Update existing student information.
- **Delete Student:** Remove student records.
- **Search:** Search students by name or roll number.
- **Data Validation:** Prevents duplicate roll numbers.
- **Charts:** Visual representation of placement status and academic performance.
- **Data Storage:** Stores student information in a JSON file.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/harshadapadwal0305/Student-Portal.git
```

**2. Open the project folder**

```bash
cd Student-Portal
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Navigate to the backend folder**

```bash
cd backend
```

**5. Run the FastAPI server**

```bash
uvicorn main:app --reload
```

**6. Open the application**

Visit:

```text
http://127.0.0.1:8000
```

## 🎯 Project Objective

The main objective of this project is to simplify student record management through a user-friendly web application. It demonstrates backend API development, frontend integration, CRUD operations, data validation, and dashboard visualization.
